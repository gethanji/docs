Is Hanji for you?

Hanji fits people who want a calm place to explore ideas, plan work and keep knowledge, while retaining their own files and choosing when an agent joins in. It can be a personal workspace or a shared instance you operate.

The preview may fit if

  • You want a canvas, planning tools and Markdown knowledge in the same workspace.
  • Local folders and Git-backed content matter to you.
  • You want to bring your own agent and control its access to the work.
  • You are willing to use an evolving Mac preview and share feedback.
  • Your team can operate its own instance or tailnet when sharing it.

Check these limits first

The desktop is shared by invitation; there is no unrestricted public binary download. Hosted workspace sync is not included. The app does not supply a model account, an enterprise identity-provider integration or a procurement-ready managed service. A teammate’s access still needs to be configured by the owner.

Local ownership also brings backup responsibilities. Repositories preserve file history, but accounts, grants, sessions and live journals have durable state outside those files. Desktop workspace, Mounts and Permissions explain what you are taking on.

If you need a supported hosted service or a finished enterprise deployment today, the current preview will not cover that need. If you want to help shape a workspace for people and agents, request preview access.
