handbook / product / features

Features

These capabilities are implemented in the current local and desktop preview. The handbook is public; the app is shared by invitation. “Available” here does not mean a general public release or a hosted service.

Think — explore ideas

CapabilityWhat it does
A shared canvasNotes, text, flowchart shapes, connectors, images, vector stickers and sections
Smooth object handlingSelection rectangles, Shift-add, move, resize, duplicate, copy/paste, grouping and undo
Intentional placementNew content appears near the viewport with space between objects
Live editingNotes update while typing; routine save chatter stays out of the way
Direct table controlsEdit cells, select ranges, add rows/columns, clear or delete selections without a model
Visual templatesBrainstorm, retrospective and decision-flow layouts; bulk notes from a list
Shared workshop toolsTimer presets, pause/resume, voting and results in an anchored panel
Searchable helpGrouped shortcuts, keyboard focus and narrow-window layouts
Canvas settingsName, live background preview, save/discard protection in a drawer
Visible agent activitySelected conductor shape, state motion, target cursor and object highlights
Links to the rest of the workspaceCreate issues from notes, write up a selection, ask the conductor
Portable checkpointsCanvas objects persisted through revisioned operations and Markdown/Git checkpoints

Think canvas covers the interaction details, permissions and limits.

Plan — make the next step clear

CapabilityWhat it does
Issues and projectsFile-backed work with owners, status, priorities, comments and linked context
Multiple viewsLists, boards and dependency canvases over the same work
Objectives and key resultsClear hierarchy, progress, confidence, check-in age and linked issues
Sensible freshnessCompleted binary results stop asking for updates; recurring metrics keep their freshness checks
Contextual conversationsWorkspace conductor and separate task sessions where configured
Shared appearanceWorkspace primary color, cool neutral surfaces and the same sidebar/search rhythm
Lightweight creationNew issue uses the shared light primary action; create before filling every detail

See Objectives and key results and The conductor. Provider accounts and live agent sessions depend on the agent setup you bring; the app includes no model.

Document — keep what matters

CapabilityWhat it does
Markdown reading and editingIn-place WYSIWYG editing over real files, with byte-fidelity checks
Structure and navigationIndented folders, shared carets, full-row mount targets and clear selected pages
Scoped searchTitles and matching passages, Hangul support, aliases and exact counts
Rich contentTables, task lists, links, highlights, images and allowed embeds
History and commentsRevisions, page discussions, anchored annotations and reversible changes
Proposal reviewReview a diff, merge or reject an agent’s branch
PublishingHTML, per-page Markdown mirrors, llms.txt and optional OKF bundles
Phone layoutsA drawer carrying the same collection and editing surface

Reading and writing, Comments, Proposals and Publish to the web cover these workflows.

Shared workspace

CapabilityWhat it does
Guided setupFour stages, automatic fresh folders, optional imports, owner access and review
Workspace identityName, logo, primary color and contrast-aware light/dark appearance
ConductorOne standing conversation across products, with context, approvals and supported Undo
Conductor appearanceOrb, Ring, Crystal, Blob, Cube or Disc, with state-specific motion
Workspace insightsRecorded contributions, seven-day comparisons, product mix and human/agent attribution
Independent Activity and SettingsWorkspace views that do not force a product switch
People and scopesPer-mount/path grants, content visibility and scoped agent tokens
Tailnet accessUse your own network and authorize who can reach the workspace
Local ownershipFiles and durable configuration under your control; no per-token product metering

Desktop workspace, Workspace insights and Permissions explain the shared surface. Hosted sync, a bundled model account and an unrestricted public binary download are not included. Where we are separates current work from future direction; Changelog preserves the history.
