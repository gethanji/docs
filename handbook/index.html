handbook

Start here

Hanji is a workspace for people and agents to explore ideas, organize work and keep knowledge. Our mission is to help them build shared understanding on a foundation they own.

Today's desktop preview is the first step: Think for visual exploration, Plan for issues, projects and objectives, and Document for knowledge in Markdown. The conductor brings an optional agent into the context of that work.

Understand the whole workspace

Start with What Hanji is for the product and its boundaries. Read Mission and vision for the larger ambition. Then follow From idea to action: a concrete example of exploring a question, giving the next step an owner, and preserving the decision.

This handbook describes the working preview. The Mac app is shared by invitation; public binary downloads and a hosted workspace service are not available yet. Preview access and setup.

Make a workspace

Desktop workspace covers receiving the preview, moving the app to Applications and creating a workspace. The setup has four stages: your workspace, your content, secure access and a review. Start fresh prepares the selected products’ folders; existing content can be connected during setup or later.

Quick start helps you choose that path or the path for an existing source checkout. You can read, edit and organize without connecting a model account.

Go a little deeper

Using Hanji is the complete guide map. Features lists what the preview implements. Permissions explains who can read and change each kind of content. Mounts connects repositories, Agents connects scoped tools, and Proposals covers reviewing suggested edits.

For the project’s direction, read The story, Principles and Where we are. For the implementation, start with How it's built, The serializer, The core and The web front.

The products were previously called Write and Work. Their current names are Document and Plan; technical package and command identifiers stay stable.
